## 1. 运行时平台（Droidspaces）

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 版本查询 | ✅ | 可读取运行时版本 |
| 子命令集 | ✅ | start/stop/restart/enter/run/info/pid/show/scan/check/docs/version/daemon |
| **结构化 JSON 输出** | ✅ | `--format` 仅对 `show` / `info` / `check` 有效 |
| 能力位检查 | ✅ | `check` 返回布尔能力表（命名空间、cgroup2、overlayfs、loop 等） |
| 列表 / 详情 JSON | ✅ | `show` / `info` 返回含名称、OS、IP、资源、网络模式、转发、挂载计数等字段 |
| 进入运行时 | ✅ | `enter` / `run` 均存在；`run` 实测可执行命令 |
| **容器 PID 语义** | 🟡 | `pid` 返回**命名空间内** PID，与宿主 PID 不同，展示需注明 |
| 其余命令结构 | 🟡 | `start/stop/enter/run/pid/scan` 仅文本输出，字段稳定性待观察 |
| 配置字段 | ✅ | 配置为 `key=value`，含网络/挂载/端口/自启等键 |
| 端口转发机制 | ✅ | 配置中的 `port_forwards` 表达“Android 端口:运行时端口/协议” |
| NAT 规则状态 | ✅ | 存在可读的规则状态记录（逐条 DNAT 相关） |
| 守护进程可达 | ✅ | 守护进程响应命令 |
| 自启动编排 | ✅ | 模块脚本按“自启标记 + 优先级 + 网关依赖”启动容器 |
| `show` 计数/uptime | 🟡 | 观察到总数与运行数不一致、uptime 为 0，疑似缺陷，需交叉校验 |

## 2. Docker / Compose（运行时内部）

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 引擎版本/API | ✅ | 客户端/引擎版本一致；API 版本与最低兼容版本已知 |
| 容器列表 | ✅ | 名称/镜像/状态/端口可读 |
| Socket | ✅ | unix socket，权限受限（root 组可读写） |
| Compose 可用 | ✅ | `docker compose ls` 可用，版本存在 |
| Compose 归属发现 | ✅ | 依赖 compose 标签（project / service / config_files），可靠 |
| 裸容器区分 | ✅ | 非 compose 容器标签为空，可据此区分 |
| 配置文件可读 | ✅ | compose 配置文件在运行时内可读（是否对外暴露需脱敏） |
| 端口发布关系 | ✅ | 可读容器端口 → 运行时端口映射 |
| 拉镜像 / exec / up-down | ❌ | P0 明确禁止，不作为能力面 |

## 5. 网络与代理

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 监听元数据（运行时内） | ✅ | 可读本地监听表 |
| 主机侧真实监听 | ❔ | 仅有配置与规则意图，需宿主侧核对 |
| 两级端口模型 | ✅ | Docker 发布 → 运行时转发 → 宿主，链路可读 |
| 代理 controller 可达 | ✅ | 绑定回环地址 |
| 代理 controller 鉴权 | ✅ | **无 secret 行**（即回环上无鉴权） |
| 代理 mode 读取 | ✅ | 可读当前 mode |
| 守卫覆盖行为 | 🟡 | 存在周期守卫脚本会改写 mode；**是否覆盖人工切换为强推断，需一次写入才能证实** |
| VPN 实现 | ❌ | 明确不做；只接已有内核 |
| 网段扫描 / ping / 路由查询 | ❌ | P0 禁止 |

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 既有统一执行器 | ✅ | 存在多模式执行入口（运行时内 / 宿主 root / 其他） |

---

## 7. 结论摘要

- **可依赖**：`--format` JSON（show/info/check）、Docker 引擎与 Compose、compose 标签、systemd/journald、文件元数据、端口两级链路的**配置与规则意图**。
- **需谨慎**：`pid` 的命名空间语义、`show` 计数/uptime、非 JSON 命令的文本解析、主机侧真实监听、热生效。
- **不可用/禁止**：Docker TCP、无认证 root HTTP、VPN 实现、网段扫描。
- **高风险待验证**：端口/挂载写入的热生效、代理守卫对人工切换的覆盖窗口。
