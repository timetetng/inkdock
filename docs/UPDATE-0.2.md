# 0.2 开发记录

- 容器列表与详情增加 Docker stats 的 CPU、内存、内存比例、网络累计 I/O、块设备累计 I/O、进程/线程计数。前台概览/服务页每五秒发起一次有界快照请求，不后台常驻采样；失败单独显示，停止的容器不伪造零值。
- 网络详情显示 host/bridge 等模式。host 模式通过 docker top PID 与 ss 实际监听归属匹配；运行时 NAT 地址来自 Droidspaces JSON，不硬编码私人 IP。仅展示通配或运行时地址绑定，不将回环监听误报为宿主可达。
- bridge 显示真实发布记录，暂无发布记录不再称为“没有端口”。
- 地址支持复制和明确标记的“尝试 HTTP”，不声称自动识别协议或连接成功。
- 日志从小弹窗改为独立全屏页面：等宽字体、行号、错误/警告颜色、搜索、级别过滤、横向滚动/换行、手动刷新、文字选择和复制筛选结果。
- 日志仅最近150行快照，不假装实时跟随；多行堆栈的级别过滤是逐行启发式，不声称结构化解析。关闭清除页面日志，未实现文件导出。
- 待验收：Android 真机视觉与交互、不同网络模式和 IPv6、Docker stats 内核隔离指标准确性。host 网络的 Docker NetIO 可能为空或不具备容器级隔离意义，不视为每服务真实网络流量。
